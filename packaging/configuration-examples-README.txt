Configuration examples

These files are samples. They are optional.

On first launch the game writes its own config under BepInEx/config/. You do not need to copy the samples. If you have already edited your config, do not overwrite it with a sample.

SpiffoAiCompanions.cfg is the sample for this mod.
Maddhattr.OfflineCompanionsReborn.cfg is the sample for the integrated Reborn settings.

The current package is at:
https://github.com/NotUrSpiffo/Spiffos-AI-Companions/releases/latest
